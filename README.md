# منصة وشجرة فخذ ذوي عويض — من البصصة الشدادين من بني الحارث

منصة رقمية تفاعلية والهوية البصرية الرسمية لفخذ **ذوي عويض** (ديار **قيا — جنوب الطائف**).

## المكوّنات الرئيسية للمشروع
- **الشجرة التفاعلية (`index.html`)**:
  - شجرة نسب ديناميكية قابلة للفتح والطي عبر ٨ فروع رئيسية و ٧٦٠ اسماً موثقاً، مع خيار إظهار عمود النسب متصلاً حتى قحطان.
  - **البوصلة النسبية**: مخطط دائري تفاعلي لتصفح كثافة الفروع والأجيال.
  - **الدليل والبحث الذكي**: بحث فوري يدعم تطابق الهمزات والتاء المربوطة وسلاسل النسب المتعددة.
  - **حاسبة صلة القرابة (وش يقرب لي؟)**: إيجاد الجد الجامع ورسم مسار القرابة على الشجرة مباشرة.
  - **لوحة الإحصائيات**: توزيع الأجيال والفروع وأكثر الأسماء تكراراً، مع إمكانية تنزيل بطاقة نسب فاخرة وتصدير صورة الشجرة.
- **استوديو الهوية البصرية والشعار (`brand/logo-studio.html`)**:
  - ٣ مقترحات شعار مرتبطة بحصن قيا الحجري وجبال قيا وبسل والمطية العربية، ولوحة الألوان والخطوط الرسمية مع تحميل مباشر بصيغتي `SVG` و `PNG`.
- **ورق المراسلات الرسمي (`brand/letterhead-clean.html` و `brand/letterhead-official.html`)**:
  - قوالب `A4` جاهزة للطباعة أو الحفظ بصيغة `PDF`.

## التشغيل والمعاينة محلياً
يمكن فتح الملف `index.html` مباشرة في المتصفح أو تشغيل خادم محلي:

```bash
python -m http.server 8765
```

## النشر عبر GitHub Pages
الموقع ثابت بالكامل (`Static HTML/CSS/JS`) ولا يتطلب أي خادم خلفي أو خطوات بناء، ويمكن تفعيل `GitHub Pages` مباشرة من الفرع `main` والمجلد الجذري (`/`).
